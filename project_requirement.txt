# 4. 🧩 Functional Requirements (Deep + Real)

---

## 4.1 Authentication Service

### Features:

* Login / Register
* JWT + Refresh Token
* Logout (token invalidation)

### Flows:

1. User logs in
2. Access token issued
3. Refresh token stored securely

### Edge Cases:

* Token reuse attack
* Multiple device sessions
* Expired refresh token

---

## 4.2 User Service

### Features:

* CRUD users
* Assign roles
* Activity tracking

### Constraints:

* Unique email
* Soft delete only

---

## 4.3 CRM Core Service

### Modules:

#### Leads

* Create / update / assign
* Status pipeline

#### Deals

* Pipeline stages
* Revenue tracking

#### Tasks

* Assign + deadlines
* Notifications

---

## 4.4 🔐 Locker Service (Critical Feature)

### Core Logic:

* Data encrypted before storage
* Access is request-based

### Flow:

1. Admin stores secret
2. User requests access
3. Admin approves (time-limited)
4. Access auto-revoked

### Edge Cases:

* Expiry not enforced → critical bug
* Concurrent access requests
* Unauthorized access attempts

---

## 4.5 Notification Service

* Email queue
* Event-driven triggers

---
